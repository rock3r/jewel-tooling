Jewel Tooling helps Compose UI authors see parameter stability in the editor and record live composition from a local run. You do not add a dependency, change application source, or start a server for the hints.

  • Editor hints. Stability estimates appear beside @Composable parameters in project files and attached library sources. Hover for the reason. Use the gutter icon or Inspect Compose Stability to see every input in one place.
  • Live inspection. Run with Compose Inspection starts your existing configuration with a bundled agent. The Compose Inspection tool window shows execution counts, inclusive durations, filters, and clickable duration badges in matching Kotlin files.
  • Recordings. Export a session, import a saved file from the tool window or Tools → Open Compose Recording, and close it when you are done.
  • Coding agents. Tools → Compose Analysis MCP Server… exposes the same static analysis to a local coding client, with an optional agent skill.
  • Customisation. Toggle inlays and gutters, and change colours under Settings → Editor → Color Scheme → Jewel Tooling.

Requires IntelliJ IDEA 2026.2 or newer with bundled Kotlin in K2 mode. Stability and inclusive duration are observations. They do not prove skipping, frame time, or a performance problem.
